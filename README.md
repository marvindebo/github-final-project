# Simple Interest Calculator

A Bash-based Simple Interest Calculator developed as part of the IBM Getting Started with Git and GitHub final project.

## Project Description

This open-source project calculates simple interest using three values supplied by the user:

- Principal amount (P)
- Annual interest rate (R)
- Time period in years (T)

The calculator uses the formula:

Simple Interest = (P × R × T) / 100

## How to Run

1. Clone or download this repository.
2. Open a Bash terminal.
3. Run `bash simple-interest.sh`.
4. Enter the principal, annual interest rate, and time period when prompted.
